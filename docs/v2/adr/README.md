# V2 架构决策

本目录存放依据 Experiment 证据形成的架构决策。本说明本身不是 ADR，也未采用任何 Candidate。

ADR 应包含背景（Context）、决策（Decision）、替代方案（Alternatives）、证据（Evidence）、权衡（Trade-offs）和后果（Consequences）。关联 Research Question、Baseline、数据集 / 协议、Benchmark 结果及相关 Task。记录接受 / 拒绝 / 暂缓状态、人工决策引用、结论有效条件及下一步应验证的内容。缺乏支持证据的选择继续等待人工判断。

负向 Experiment 也是有效证据。实验代码或 ADR 提案不构成生产集成授权：[docs/v2/SPEC.md](../SPEC.md) 的 EXP-02 要求具备已记录的人工决策和明确的实现 Task。
